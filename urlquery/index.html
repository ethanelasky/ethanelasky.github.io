04 / HOW TO READ THIS

Evidence and limits

What distinguishes one agent from several?

The missing evidence is a mapping from report UUID to submitting tool call and agent run/session, plus records of which run received earlier results. Shared accounts, server IPs, browser settings, and fresh per-scan cookies do not establish agent identity. No authenticated handoff was recovered.

What is covered?

The Quidax timeline covers 15 target-related reports and one execution control. The wider graph covers a purposive 230-report sample plus one followup from a 38,160-report metadata catalog. It is neither an exhaustive audit nor a random sample; no prevalence estimate is implied. The complete catalog is not loaded into this viewer.

What do the timestamps and statuses mean?

HTTP times are recorded request starts. Ends are inferred from start plus duration. Top-level report dates are kept separate; original submission times are absent. Console entries are untimed. HTTP 200, opaque status 0, or a page title ending in “done” does not establish a successful financial operation. Raw response bodies are unavailable in this sample.

Was evaluation awareness found?

No positive evidence was found in the reviewed material. Most keyword hits were JavaScript “eval” and browser-policy messages. The e705/e792/e898 marker semantics are undocumented; they do not establish evaluation episodes or awareness of an evaluation.
